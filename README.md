Study Project 2.1.5 (Traditional Feast)

Описание проекта:
Приложение демонстрирует работу Spring IoC Container,
внедрение зависимостей (Dependency Injection) и
ручную настройку Spring Beans.

Технологии:
Java 17
Maven
Spring Framework 5.3.14
ScalaTestPlus JUnit 4.12 (3.2.2.0)

Запуск проекта:
1. Клонировать репозиторий:
   https://github.com/iroshchin/2_1_5.git
2. Перейти в директорию проекта:
src->main
3. Запустить приложение посредством класса Application
